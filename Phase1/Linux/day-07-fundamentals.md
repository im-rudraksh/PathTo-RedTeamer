## Why this matters for hacking
- `nc -lvnp` — setting up listeners, used for catching reverse shells in real engagements
- `cron` — job scheduler, misconfigured cron jobs are one of the most common privilege escalation vectors
- `md5sum` — hashing, predicting filenames generated by privileged scripts
- `&>/dev/null` — hiding output, attackers use this to run silent background processes
- Logic analysis — predicting what a privileged script does without executing it yourself
